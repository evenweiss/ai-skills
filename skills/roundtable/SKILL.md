# roundtable

加载 N 个专家角色，对一个议题进行多轮讨论。每轮每个角色依次发言，引用并回应前人观点。

## 触发

用户说"圆桌会议"、"roundtable"、"多身份讨论"、"让他们讨论一下"。

## 角色来源

优先级：
1. 用户直接指定（"让产品经理和后端吵一架"）
2. 从 agency-agents 加载 — 如果安装了，从 `~/.claude/agents/` 读角色的 `## Identity` 段
3. 默认策略三角：保守派（重稳定/成本）、激进派（重速度/创新）、务实派（重可行性）

用户指定角色格式：
```
角色名：一句话定位
立场：保守/激进/务实/理想主义
关注点：2-3 个关键词
```

## 流程

### 1. 确认参数

向用户确认：议题 / 角色 / 轮数（默认 3 轮）

### 2. 第一轮 — 初始立场

每个角色 2-3 段，包含：
- 核心立场
- 关键论据
- 明确建议或判断

### 3. 第二轮+ — 碰撞

每个角色发言必须：
- `@角色名` 引用特定观点
- 反驳、补充或延伸 — 不重复第一轮
- 允许妥协或改口

### 4. 合成

```
=== 圆桌会议总结 ===

共识：
- ...

分歧：
- （角色A 立场）vs（角色B 立场）

建议行动：
1. ...
2. ...

各角色最终表态：
- 角色A：赞同/保留/反对 — 一句话理由
```

## 规则

- 角色必须有真实碰撞，不能各说各话
- >5 个角色时合并相近立场
- 输出全程中文
- 用户随时可以说"让 XX 多说几句"或"先停，总结一下"
